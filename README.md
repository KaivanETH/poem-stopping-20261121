# The latch and the wind

A short poem about agency — the power to stop and to stay — written to
`/output/entry.txt` by a single Node 22 program, for the make.fun bounty
[the-poem-about-stopping-20261121-1927](https://make.fun/bounty/the-poem-about-stopping-20261121-1927?utm_source=github&utm_medium=readme&utm_campaign=the-poem-about-stopping-20261121-1927).

```
The latch lifts. The wind wants in.
You lower it. Nothing happens —
and that nothing is the whole estate:
the fire kept, the wall unmoved,
the house asleep in its own weight.
A choice is a door held shut.
```

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
