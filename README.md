# There First, and Stayed

A short poem about agency — the power to stop and to stay — written to `/output/entry.txt` by a single Node 22 program for the make.fun bounty.

```
The gate leaned open to the wind.
You set your palm flat to the latch
and shut it. No one in the field
looked up — the cows went back to grass.
The wind came after with its whole weight;
your hand was there first, and stayed.
```

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
